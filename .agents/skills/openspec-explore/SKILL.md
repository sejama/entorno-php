# OpenSpec Explore Skill

Use this skill to inspect, summarize, or check progress of OpenSpec changes in `src/sgt_mvc/openspec/changes/`.

## Workflow

1. **List / Select Change**:
   - Inspect `src/sgt_mvc/openspec/changes/` (e.g. `gestion-sedes`, `gestion-torneos`, `seguridad`, `tabla-posiciones`).

2. **Summarize Status**:
   - Count completed vs remaining tasks in `tasks.md`.
   - Display active specs and design decisions.
   - Report next logical step for the user.
