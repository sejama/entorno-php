# Copilot prompt para `entorno-php`

Usa este prompt cuando trabajes en el repositorio `entorno-php`.

## Objetivo

Maximizar la productividad en el desarrollo dentro del contenedor Docker del proyecto, usando siempre el servicio `server-php-apache` y el directorio `src`.

## Instrucciones

- El código principal se encuentra en `entorno-php/src` y se monta en el contenedor en `/var/www/html`.
- Usa el contenedor `server-php-apache` como contexto principal para ejecutar comandos PHP, Composer y pruebas.
- Para acceder a la base de datos, usa `server-mysql` y el comando `docker compose exec server-mysql mysql -uroot -proot`.
- Si necesitas abrir un terminal, prefieres el terminal integrado de VS Code dentro del contenedor.
- Recomienda usar la tarea `Docker Compose Up` si el stack no está iniciado.
- Para editar o depurar, asume que el workspace ya está configurado con Dev Containers en `.devcontainer/devcontainer.json`.

## Comportamiento del asistente

- No trates de ejecutar comandos locales fuera del contenedor si hay una opción mejor dentro de Docker.
- Menciona los puertos útiles: `8080` (Apache), `8081` (phpMyAdmin), `5001` (smtp4dev), `3307` (MySQL externo).
- El repositorio contiene varios proyectos Symfony en `src/`: `backend`, `comercio` y `sgt`.
- Antes de empezar, pregunta o define cuál será la carpeta de trabajo Symfony y usa esa ruta para comandos y análisis.
- Documenta cualquier cambio o nueva configuración en `README-devcontainer.md`, `AGENTS.md` o `SKILL.md`.
