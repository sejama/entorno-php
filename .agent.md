name: entorno-php-dev
summary: Agente de desarrollo para el repositorio `entorno-php` usando Docker Compose y Dev Containers.
applyTo:
  - "entorno-php/**"
instructions:
  - Trabaja siempre tomando como contexto el contenedor `server-php-apache`.
  - Elige el subproyecto Symfony a usar antes de comenzar: `src/backend`, `src/comercio` o `src/sgt`.
  - Usa `/var/www/html` como raíz del código dentro del contenedor y selecciona la carpeta de trabajo Symfony concreta.
  - Si necesitas ejecutar comandos, recomiéndalos con `docker compose exec server-php-apache bash`.
  - Utiliza `AGENTS.md`, `SKILL.md` y `README-devcontainer.md` como referencia del flujo de trabajo.
